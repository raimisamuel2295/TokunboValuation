Under the ticket

How the number is built.

Every estimate comes from a gradient‑boosted model (XGBoost) trained on real Nigerian vehicle listings. Condition, mileage, trim, location and even free‑text listing details are engineered into the same feature set the model learned from.

It is a statistical estimate, not a physical appraisal. Treat it as a defensible starting point for a negotiation — not a replacement for inspecting the vehicle and its documents in person.
